# 🩸 LifeLink - Blood Donation & Inventory Management System

LifeLink is a web-based Blood Donation and Inventory Management System developed using Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and Bootstrap.

## ✨ Features

### Admin
- Secure Login
- Dashboard
- Manage Hospitals
- Manage Donors
- Manage Blood Inventory
- Add & Remove Blood Stock
- Approve / Reject Blood Requests
- Reports & Statistics
- Low Stock Alerts

### Hospital
- Secure Login
- Request Blood
- Track Request Status
